# Lightbox Collage

A photo collage maker that runs entirely in the browser. Add photos, pick a design style and a canvas ratio, and the layout, spacing and fit adjust automatically. Photos never leave your device.

## Features

- **Upload:** pick many photos at once, add a whole folder, drag and drop, or paste (up to 60 photos).
- **9 design styles:** Classic grid, Mosaic rows, Masonry columns, Editorial split, Hero + grid, Polaroid scatter, Scrapbook, Film strip, Rounded tiles.
- **13 aspect ratios:** 1:1, 4:5, 3:4, 2:3, 9:16, A4 portrait, 16:9, 4:3, 3:2, 5:4, A4 landscape, 21:9, 3:1.
- **Crop:** free crop, fixed ratios, or "match its slot", with rule-of-thirds guides.
- **Pan:** drag a photo to slide it inside its frame; Re-center resets it.
- **Reorder:** drag thumbnails in the tray, or use Earlier, Later and Make first.
- **Finish:** gap, outer margin, corner radius, drop shadow and background colour.
- **Export:** PNG or JPG at 1080, 1440, 2480 (A4 at 300 dpi) or 3600 px on the short edge, rendered from the original full-resolution photos.

## Run it

Open `index.html` in any modern browser. There is no build step and nothing to install.

To host it, enable GitHub Pages for this repository (Settings → Pages → deploy from the `main` branch, root folder).

## Notes

- HEIC photos work only in browsers that can decode them (Safari). Elsewhere, convert them to JPG first.
- Light and dark mode follow your system setting.
